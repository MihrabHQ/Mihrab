Mihrab for Linux

Version @VERSION@ · x86_64 and arm64

Add Mihrab's repository once, and it is installed, updated and removed by your system's own package manager, with the rest of your updates.

Debian, Ubuntu, Mint, Pop!_OS (apt)

sudo curl -fsSLo /usr/share/keyrings/mihrab.gpg https://mihrabhq.github.io/packages/mihrab.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/mihrab.sources https://mihrabhq.github.io/packages/mihrab.sources
sudo apt update && sudo apt install mihrab

Remove: sudo apt purge mihrab, and the two files above to drop the repository.

Fedora (dnf)

sudo curl -fsSLo /etc/yum.repos.d/mihrab.repo https://mihrabhq.github.io/packages/mihrab.repo
sudo dnf install mihrab

Remove: sudo dnf remove mihrab, and /etc/yum.repos.d/mihrab.repo to drop the repository.

openSUSE (zypper)

sudo zypper addrepo https://mihrabhq.github.io/packages/mihrab.repo
sudo zypper install mihrab

Remove: sudo zypper remove mihrab and sudo zypper removerepo mihrab.

Arch, Manjaro, EndeavourOS (AUR)

yay -S mihrab-bin

Updates come with yay -Syu. Remove: yay -R mihrab-bin.

The signing key

Both repositories are signed; apt, dnf and zypper check every update against this key before installing it.

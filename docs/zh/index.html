为每一次礼拜，也为礼拜之间的一切。

Mihrab 是穆斯林一天中安静的伴侣：礼拜时间与宣礼，带诵读、泰吉威德着色和逐词朗读的麦地那穆斯哈夫，以及礼拜之间的祈祷词与记念——无需账号，没有广告，没有统计。设定位置后，整天都能离线使用。

  • 无广告、无追踪、无账号
  • 断网也能用
  • 免费且开源

版本 2.28.2 (286) • iOS, Android, macOS • AGPL-3.0-or-later • GitHub 上的源码

安装

获取 Mihrab

各个渠道是同一个应用，由同一份源码构建。F‑Droid 版本不含 Google Play 服务。

在 Mac 上： brew install --cask mihrabhq/tap/mihrab

功能

从晨礼到宵礼，一位伴侣

礼拜

礼拜时间与到下一次礼拜的倒计时、每番礼拜的宣礼、朝向罗盘、主屏小组件——每次礼拜一触即可记录。

诵读与聆听

四种传述的完整麦地那穆斯哈夫，哈夫斯与沃尔什均有泰吉威德着色，还有逐词朗读：长按一个词，就只朗读这个词。42 位诵读者，熄屏时逐章连续诵读，经注、译本与通读计划。诵读会记住你的进度，并按时辰推荐圣行所提倡的章节。

记念

《穆斯林堡垒》中的祈祷词、赞念计数、斋月与圣行斋戒的记录，以及伊斯兰历。

只属于您

无需账号，没有广告，没有追踪。通过您本就在同步的文件夹在自己的设备之间同步，备份到您自己保存的文件，全部代码以 AGPL-3.0 开源。

应用截图

它长什么样

浅色与深色，手机与平板。穆斯哈夫就是印刷的麦地那版页面本身，而不是它的图片。截图里的应用是英文的；它同样说中文。

隐私

未经你要求，没有任何东西离开手机

一天五次你身在何处，是礼拜应用所触及的最敏感的信息。这份代码里没有账号、没有分析面板、没有广告网络，也没有崩溃上报。

留在设备上

设置、已保存的地点（加密存储）、你的礼拜日志与封斋记录。通知在本地排程。

你选择时才走网络

来自你所选来源的时间、地点搜索，以及经文页面、译文与诵读音频的下载。

根本不存在

没有广告、没有追踪器、没有分析 SDK、没有崩溃上报、没有账号。F‑Droid 版本不含 Google Play 服务。

常见问题

最先被问到的问题

这个应用免费吗？

免费。它是 AGPL‑3.0 许可下的自由软件，价格上也完全免费：没有内购、没有订阅、没有捐赠按钮。

有广告或追踪器吗？

都没有。没有广告网络、分析 SDK、崩溃上报或账号——这些库根本不在项目里。

离线能用吗？

能。设定位置后，时间在设备上推算，通知也在本地排程。

支持哪些设备？

iPhone、iPad、Android 和 Mac。Mac 上可用 Homebrew 安装。

许可

Mihrab 是 AGPL‑3.0‑or‑later 许可下的自由软件，源码在 GitHub 上。

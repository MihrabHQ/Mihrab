为每一次礼拜，也为礼拜之间的一切。

Mihrab 是穆斯林一天中安静的伴侣：礼拜时间与宣礼，带诵读、泰吉威德着色和逐词朗读的麦地那穆斯哈夫，以及礼拜之间的祈祷词与记念——无需账号，没有广告，没有统计。设定位置后，整天都能离线使用。

准确度

精确到印出的那一分钟

多数礼拜应用用一种通用方法计算时间，结果与你的清真寺所依据的时间表相差一分钟或更多。在晨礼结束时、昏礼时和封斋开始时，要紧的正是这一分钟。

因此 Mihrab 重建每个机构自己的方法——它的角度、预留量和取整方式——在你的手机上计算，并把每一个时间与公布的时间表逐一核对：每个地点，每一天。只有没有任何时间出现偏差时，才会使用这种方法。

功能

从晨礼到宵礼，一位伴侣

礼拜

礼拜时间与到下一次礼拜的倒计时、每番礼拜的宣礼、朝向罗盘、主屏小组件——每次礼拜一触即可记录。全屏礼拜提醒如同闹钟；每番礼拜可选宣礼、提示音或静音；在 Android 上，手机在礼拜期间保持安静。稍后提醒只提供礼拜时间还容许的时长，直到时间结束前的「最后机会」。时间与 Diyanet、瑞典、摩洛哥和阿尔及利亚宗教部以及 Kemenag 公布的时间表精确到印刷的分钟，在手机上计算；MUIS、JAKIM 和 Türkiye Takvimi 按公布原样；其他地方使用 AlAdhan。极简模式下，「今天」只留下天空和倒计时；向上滑动查看当天时间，并像完整页面一样左右滑动切换日期。

诵读与聆听

四种传述的完整麦地那穆斯哈夫，哈夫斯与沃尔什均有泰吉威德着色，还有逐词朗读：长按一个词，就只朗读这个词。59 位诵读者（包括沃尔什、卡伦和舒尔巴传述），熄屏时逐章连续诵读，经注、译本与通读计划。诵读会记住你的进度，并按时辰推荐圣行所提倡的章节。另有 15 行的 IndoPak 印本，作为诵读哈夫斯传述的第二种方式。

背诵

标记你已背下的内容——在全部 114 章的网格上整章标记，第 30 本和第 29 本各只需轻点一次，或直接在阅读器中标记一段：“背到这里”。每一段都有自己的复习周期：背熟后第一天，然后是第三、七、十四和三十天——并且永远不会超过你自己设定的上限：一周、两周或一个月。每次背诵之后，你说明情况：“需要提示”让这一段回到每天，“还行”前进一步，“熟练”跳过一步。今天的复习是一份由你决定长度的清单，附带每日提醒；三十个方格显示每一本你已背下多少。

记念

《穆斯林堡垒》中的祈祷词、赞念计数、斋月与圣行斋戒的记录，以及伊斯兰历。

只属于您

无需账号，没有广告，没有追踪。通过您本就在同步的文件夹在自己的设备之间同步，备份到您自己保存的文件，全部代码以 AGPL-3.0 开源。浅色、深色或纯黑，六种配色主题——或“天空”，以倒计时上方的天空为整个应用上色，可选写实或鲜明的色彩。

隐私

无账户、无追踪——每个请求都写明

一天五次你身在何处，是礼拜应用所触及的最敏感的信息。这份代码里没有账号、没有分析面板、没有广告网络，也没有崩溃上报。

留在设备上

设置、已保存的地点（加密存储）、你的礼拜日志与封斋记录。通知在本地排程。

哪些内容经过网络

礼拜时间：瑞典、Diyanet 所列地点、摩洛哥、阿尔及利亚和印度尼西亚在手机上计算；其他地方由 AlAdhan 接收你的坐标。使用自动定位时，会向 OpenStreetMap 查询你所在城镇的名称，位置约取整到一公里。另有来自项目 GitHub 的小型更新文件，以及你要求的下载。没有任何内容发给开发者。

根本不存在

没有广告、没有追踪器、没有分析 SDK、没有崩溃上报、没有账号。所有 Android 版本（包括 Play 商店版本）都不含 Google Play 服务。

常见问题

最先被问到的问题

这个应用免费吗？

免费。它是 AGPL‑3.0 许可下的自由软件，价格上也完全免费：没有内购、没有订阅、没有捐赠按钮。

有广告或追踪器吗？

都没有。没有广告网络、分析 SDK、崩溃上报或账号——这些库根本不在项目里。

离线能用吗？

可以。瑞典、Diyanet、摩洛哥、阿尔及利亚和印度尼西亚的时间在手机上计算；使用 AlAdhan 时，通过 Wi‑Fi 获取后会保存未来一年。通知在设备上本地安排。

支持哪些设备？

iPhone、iPad、Android 和 Mac。Mac 上可用 Homebrew 安装。

为什么 Mihrab 的时间与其他应用不同？

多数应用使用一种通用方法，结果与你的清真寺所依据的时间表相差一分钟或更多。在适用 Diyanet、摩洛哥和阿尔及利亚的部委、Kemenag 或瑞典时间表的地方，Mihrab 给出的就是印出的那一分钟：采用机构自己的方法，并逐日与其公布的时间表核对。其他地方则使用 AlAdhan 或你选择的方法。

时间表最后公布的日期之后会怎样？

方法会在没有修正表的情况下继续单独计算。在已核对的时间里，方法本身除极小一部分外都落在印出的那一分钟上，而这一小部分只差一分钟，绝不会更多；应用会在“今日”页面上说明这一点。下一批月份公布并核对后，新的修正表无需更新应用即可送达。

我怎样自己核对时间？

把 Mihrab 月视图中的一周与你所依据机构印出的时间表对照。这些方法、核对每个时间的脚本以及它写下的记录，都公开在 GitHub 上的 mihrab-methods 仓库中。

Mihrab 隶属于 Diyanet 或某个部委吗？

不。Mihrab 是独立的，与其时间表相符的任何机构都没有隶属关系，也未获其认可。凡涉及时间本身的问题，都以该机构自己的公布为准。

Mihrab 会追踪我的位置吗？

不会。没有统计分析，没有广告网络，也没有账号。坐标只在两种请求中离开手机，且都不发给开发者：当 AlAdhan 是你的时间来源时发给 AlAdhan；使用自动定位时发给 OpenStreetMap 以查出你所在城镇的名称，并取整到约一公里。选择在设备上计算并手动输入城镇，这两种请求都不会发出。

不安装任何东西可以使用 Mihrab 吗？

可以。Mihrab 网页版在浏览器中运行，网址是 mihrabhq.github.io：你所在地的礼拜时间、标签页开着时每番礼拜的通知，以及完整的《古兰经》。设置和书签保存在该浏览器中。

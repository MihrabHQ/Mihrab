Для каждого намаза — и для всего, что между ними.

Mihrab — спокойный спутник мусульманина на весь день: время намаза и азан, мединский мусхаф с чтением, цветным таджвидом и озвучкой отдельных слов, а между намазами — дуа и зикр. Без аккаунта, без рекламы, без аналитики. Как только задано местоположение, день работает и без сети.

  • Без рекламы, трекеров и аккаунта
  • Работает без интернета
  • Бесплатно, открытый код

Версия 2.36.0 (295) • iOS, Android, macOS • AGPL-3.0-or-later • Исходный код на GitHub

Установка

Установить Mihrab

Одно и то же приложение во всех каналах, собранное из одного исходного кода. Ни одна сборка для Android, включая сборку из Play Store, не содержит сервисов Google Play.

Apple

На Mac:
brew install --cask mihrabhq/tap/mihrab

Android

Рекомендуем Obtainium: каждая версия первой, и обновляется само. Нет приложения? Установите Obtainium

Windows

Linux Предварительная версия

Debian, Ubuntu, Mint (apt)

Установить

sudo curl -fsSLo /usr/share/keyrings/mihrab.gpg https://mihrabhq.github.io/packages/mihrab.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/mihrab.sources https://mihrabhq.github.io/packages/mihrab.sources
sudo apt update && sudo apt install mihrab

Удалить вместе с настройками

sudo apt purge mihrab && rm -rf ~/.config/Mihrab
Fedora (dnf)

Установить

sudo curl -fsSLo /etc/yum.repos.d/mihrab.repo https://mihrabhq.github.io/packages/mihrab.repo
sudo dnf install mihrab

Удалить вместе с настройками

sudo dnf remove mihrab && rm -rf ~/.config/Mihrab
openSUSE (zypper)

Установить

sudo zypper addrepo https://mihrabhq.github.io/packages/mihrab.repo
sudo zypper install mihrab

Удалить вместе с настройками

sudo zypper remove mihrab && rm -rf ~/.config/Mihrab
Arch, Manjaro, EndeavourOS (pacman, yay)

Установить

curl -fsSL https://mihrabhq.github.io/packages/mihrab.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 28BB36D6D8388A8EF15EEA24E19DCF135A3D8035
printf '\n[mihrab]\nServer = https://mihrabhq.github.io/packages/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu mihrab

Удалить вместе с настройками

sudo pacman -R mihrab && rm -rf ~/.config/Mihrab

Приложение целиком работает на компьютере, и мы ищем тех, кто его протестирует. Сообщите, что не работает

Скриншоты

Как это выглядит

Каждая функция — на том устройстве, для которого она сделана: сначала телефоны, затем iPad, Mac, Windows и Chromebook, в теме «Небо» через часы одного дня. Мусхаф — это сама печатная мединская страница, а не её снимок. На экранах приложение по-английски; по-русски оно говорит так же.

Из магазинов

Что пишут люди

Пять звёзд, их собственными словами — так, как они написали в Google Play и App Store.

Возможности

Один спутник — от фаджра до иша

Молитесь

Время намаза с обратным отсчётом до следующего, азан для каждого намаза, компас киблы, виджеты — и каждый намаз отмечается одним касанием. Полноэкранное напоминание о молитве, как будильник, для каждого намаза азан, сигнал или тишина, а на Android телефон молчит во время самой молитвы. Отложить можно лишь настолько, насколько позволяет оставшееся время намаза, — вплоть до «последней возможности» перед его концом. Время до напечатанной минуты совпадает с опубликованными расписаниями Диянета, Швеции, министерств Марокко и Алжира и Kemenag и рассчитывается на телефоне; MUIS, JAKIM и Türkiye Takvimi — как опубликованы; в остальных местах AlAdhan. В минимальном режиме на экране «Сегодня» остаются только небо и обратный отсчёт; смахните вверх, чтобы увидеть время на день, и листайте дни, как на полной странице.

Читайте и слушайте

Полный мединский мусхаф в четырёх риваятах, с цветным таджвидом для Хафса и Варша и озвучкой слов: удерживайте слово — и прозвучит именно оно. 59 чтецов (в том числе в риваятах Варш, Калун и Шуба), тилява сура за сурой с выключенным экраном, тафсир, переводы и план хатма. Тилява помнит, где вы остановились, и предлагает то, что сунна советует читать в этот час. А также 15-строчный мусхаф IndoPak — второй способ читать Хафс.

Заучивание

Отмечайте то, что знаете наизусть: целые суры на сетке из всех 114 — джуз 30 и джуз 29 по одному касанию — или отрезок прямо из читалки: «Выучено до этого места». У каждой части свой цикл повторения: через день после заучивания, затем через три, семь, четырнадцать и тридцать дней — и никогда дольше того предела, который вы задали сами: неделя, две недели или месяц. После каждого чтения наизусть вы говорите, как прошло: «Нужна была помощь» возвращает часть к ежедневному повторению, «Нормально» продвигает на шаг, «Свободно» пропускает один. Сегодняшнее повторение — список той длины, которую вы выбрали, с ежедневным напоминанием, а тридцать клеток показывают, какая доля каждого джуза уже выучена.

Поминайте

Дуа из «Крепости мусульманина», тасбих, журнал постов для Рамадана и сунна-постов и календарь хиджры.

Только ваше

Без аккаунта, без рекламы, без слежки. Синхронизация между вашими устройствами через папку, которую вы и так синхронизируете, резервная копия в файл и весь код открыт по AGPL-3.0. Светлая, тёмная или чёрная тема, шесть цветовых тем — или «Небо», которое красит всё приложение по небу над обратным отсчётом, в реалистичных или ярких цветах.

Приватность

Без аккаунта, без слежки — и каждый запрос записан

Где вы находитесь пять раз в день — самое чувствительное, чего касается приложение для намаза. В этом коде нет ни аккаунта, ни аналитики, ни рекламной сети, ни отчётов о сбоях.

Остаётся на устройстве

Настройки, сохранённые места (в зашифрованном виде), дневник намазов и журнал поста. Уведомления планируются локально.

Что уходит в сеть

Время молитв: для Швеции, мест Диянета, Марокко, Алжира и Индонезии рассчитывается на телефоне; в других местах AlAdhan получает ваши координаты. При автоматическом определении места название вашего города запрашивается у OpenStreetMap, а позиция округляется примерно до километра. Небольшие файлы обновлений с GitHub проекта и загрузки, которые вы запросили. Разработчику не уходит ничего.

Отсутствует полностью

Ни рекламы, ни трекеров, ни аналитического SDK, ни сборщика сбоев, ни аккаунта. Ни одна сборка для Android, включая сборку из Play Store, не содержит сервисов Google Play.

Частые вопросы

О чём спрашивают в первую очередь

Приложение бесплатное?

Да. Свободное ПО под лицензией AGPL‑3.0 и бесплатное: нет покупок внутри приложения, подписки и кнопки пожертвования.

Есть ли реклама или трекеры?

Ни того, ни другого. Нет рекламной сети, аналитического SDK, сборщика сбоев и аккаунта — этих библиотек в проекте попросту нет.

Работает ли без интернета?

Да. Время для Швеции, Диянета, Марокко, Алжира и Индонезии рассчитывается на телефоне; с AlAdhan год вперёд сохраняется после загрузки по Wi‑Fi. Уведомления планируются на устройстве.

Какие устройства поддерживаются?

iPhone, iPad, Android и Mac. На Mac устанавливается через Homebrew.

# Mihrab — where the plan lives

This file was the v1 one-pager ("a comprehensive Islamic prayer times
application", AlAdhan as the backend, Supabase "for user data" one day).
None of that describes the app any more — Mihrab holds nothing about
anyone on any server, and never will — so the file is a signpost now.

- **What the app is and how it is built:** [`ARCHITECTURE.md`](ARCHITECTURE.md).
- **What is open, what shipped, what is waiting on a person:**
  [`IMPROVEMENT_ROADMAP.md`](IMPROVEMENT_ROADMAP.md) — trimmed in the same
  change that lands an item.
- **The targeted rewrites** (widget contract, the Quran store split, the
  release tool, Glance widgets, the React Native upgrade):
  [`docs/rewrite-plan.md`](docs/rewrite-plan.md).
- **Design decisions**, one document each: [`docs/design/`](docs/design/)
  (principles, the sky palette, onboarding, sync) and the plans under
  [`docs/`](docs/).
- **Releases:** [`docs/DISTRIBUTION.md`](docs/DISTRIBUTION.md) is the flow,
  [`docs/release-log.md`](docs/release-log.md) what each one cost,
  [`CHANGELOG.md`](CHANGELOG.md) what each one changed.
- **The identity:** [`branding/IDENTITY.md`](branding/IDENTITY.md).

# Fonts for the store panels

- `Roboto.ttf` — Roboto (variable), SIL Open Font License 1.1, from google/fonts. The face the app sets its Latin UI in on Android.
- `Amiri.ttf` — Amiri, SIL Open Font License 1.1, the same file the app bundles (android/app/src/main/assets/fonts).

The Apple sets use the system face (SF), which is Apple's to use for Apple-platform marketing; Urdu uses the system's Noto Nastaliq Urdu.
